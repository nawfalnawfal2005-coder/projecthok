# Tooliva — نظام التصميم v3 (معاينة تجريبية)

مجلد تجريبي معزول **لا يلمس المشروع الحقيقي**. نموذج ثابت (HTML/CSS/JS)
لنظام التصميم الجديد للمراجعة قبل النقل إلى Next.js/React.

## كيف تشاهده؟
افتح في المتصفح (نقرة مزدوجة):
- `index.html` — الصفحة الرئيسية الكاملة
- `tool-page.html` — صفحة أداة (PDF → Word) + عرض توضيحي متحرك

## البنية
```
assets/
  reset.css         — إعادة الضبط + حلقة التركيز + تقليل الحركة
  tokens.css        — متغيرات التصميم + نظاما ألوان (برتقالي/زمردي)
  components.css    — كل المكوّنات + الرسوم المتحركة
  app.js            — محرّك عام: i18n، تبديل اللون، بحث، محاكاة، عدّادات
  i18n/
    ar.js           — النصوص العربية (مصدر الحقيقة الوحيد للعربية)
    en.js           — النصوص الإنجليزية (مصدر الحقيقة الوحيد للإنجليزية)
```

## الترجمة الاحترافية (بدون تكرار)
- **لا يوجد أي نص في HTML** — العناصر تحمل مفاتيح فقط `data-i18n="key"`.
- **كل لغة في ملف مستقل** — لا تختلط اللغتان في مكان واحد.
- المحرّك العام يقرأ ملف اللغة النشط ويطبّق النص + الاتجاه `dir` + `lang` + العنوان + وصف الصفحة.
- الاختيار **يُحفظ تلقائياً** في المتصفح (localStorage).
- مبدّل لغة **مقسّم أنيق** (عربي | EN).

## الرسوم التوضيحية المتحركة
1. **أنبوب تحويل متحرك** في صفحة الأداة — PDF ← (نقاط متدفقة) ← تروس تدور ← Word، مع خط مسح ضوئي.
2. **أيقونات متحركة** في قسم "كيف تعمل" — سهم رفع، ترس دوران، سهم تنزيل.
3. **درع خصوصية متحرك** بخط مسح ضوئي في قسم "لماذا Tooliva".

## المعالج (الرفع → الفحص → المعاينة → الإعدادات → المعالجة)

صفحة الأداة **4 خطوات** بشريط تقدّم:

1. **الرفع + الفحص السريع** — منطقة رفع قابلة للوصول، ثم قائمة تحقق متحركة (الحجم، النوع، الاسم، التوقيع) تنتقل تلقائياً.

2. **المعاينة (استوديو احترافي)** — عمودان:
   - **شريط الصفحات**: صورة مصغّرة لكل صفحة + **مربع اختيار** لتضمين/استثناء الصفحة + حذف عند التمرير.
   - **العارض**: تحكم كامل بالفأرة — عجلة الفأرة للتكبير • السحب للتحريك (pan) • نقرة مزدوجة للتكبير • تدوير • ملاءمة العرض • ملاءمة الصفحة • ملء الشاشة • إعادة الضبط • اختصارات لوحة المفاتيح (الأسهم للتنقل، `+`/`-` للتكبير، `R` للتدوير، `0` للإعادة).
   - **محتوى حقيقي**: كل صفحة تعرض عنواناً وفقرة ونصاً وجدولاً — ليتضح ما تُعالجه الأداة.

3. **الإعدادات** (خيارات قابلة للدمج في المشروع) — بطاقات واضحة:
   | البطاقة | الخيارات |
   |---|---|
   | **الملف الناتج** | اسم الملف • الصيغة (Word .docx / Word 97 .doc / RTF / TXT) • وضع التحويل (حفاظ على التخطيط / نص قابل للتحرير) |
   | **الصفحات** | عدّاد الصفحات المحددة • تحديد الكل / مسح • "استخدام المحددة فقط" • ملف واحد / ملف لكل صفحة |
   | **المحتوى** | الصور • الجداول • الروابط • التعليقات • OCR + لغة التعرف (عربي/إنجليزي/كلاهما) |
   | **الجودة والحماية** | جودة (عالية/متوسطة/منخفضة) • حماية بكلمة مرور |
   | **ملخص حيّ** | الوضع • الصيغة • الصفحات • الحجم التقديري |

4. **المعالجة** — شريط تقدم ثم نجاح وتنزيل.
